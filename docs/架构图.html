模型层 · llm.py
Chat：硅基流动 DeepSeek（OpenAI 兼容，json_mode 结构化输出，抽取关 thinking 降本）
Embedding：阿里 DashScope qwen3.7-text-embedding（1024 维，10 条/批自动分批）
数据层 · data/（全合成，仅本地）
policies/：P-01~P-05 采购审核制度（预付款/质保/责任上限/保密/IP与法律）
contracts/：sample_01~09 合成合同（md+docx+pdf 三格式同源，4 品类）
uploads/：用户上传文件落盘（thread_id 命名）
存储层 · store.py + policy_rag.py
ThreadStore：进程内任务登记簿（thread_id→状态/闸口载荷/报告/原文），线程安全
MemorySaver：LangGraph checkpointer（进程内存，服务重启即失）
政策向量库：Milvus（HNSW+COSINE，insert 后 flush）/ 内存检索兜底（auto 探测）
关键设计决策：① 抽取层"LLM 原样抄金额/日期 + 确定性归一化"，避免模型格式化漂移；② 规则引擎纯函数无 LLM，可离线单测，政策阈值集中定义；③ 高风险强制 HITL（interrupt + Command resume），审批三动作留痕；④ 单 worker 顺序处理防并发打爆 LLM；⑤ 全合成数据（合规），政策库检索回指 P-编号防"凭空判断"。
